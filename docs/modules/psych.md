# 心理学维度

从聊天行为反推心理倾向。**不是心理诊断**，也不能替代当面了解。

## 为什么要做这一层

墨溯原本的画像只回答「几点在聊、说了什么词」——那些是事实，但用户真正想知道的是
「这个人怎么样」。从行为数据到心理特征中间必须有一层可审计的推理，否则就是算命。

本模块的纪律只有一条：

> **不给结论性标签，只给「行为证据 → 可能倾向 → 置信度 → 反例」。**

不说「她焦虑型依恋」，而说：

> 我方主动开启对话的比例 **78.3%**（样本 83）
> 对方平均回复耗时 / 我方平均回复耗时 **1.47**（样本 147）
> ⚠️ 反例可能：也可能只是对方工作时段不看手机
> → 依恋倾向·焦虑面：**证据中等**

## 六个维度

| 维度 | 看什么行为 | 依据 |
|------|-----------|------|
| 依恋倾向·焦虑面 | 我方发起比例、双方回复耗时比 | Hazan & Shaver 依恋理论的行为面 |
| 依恋倾向·回避面 | 我方回复更慢 + 主动发起低 | 同上 |
| 爱的语言倾向 | 我方消息里哪类表达最多 | Chapman 五类爱的语言 |
| 情绪表达与调节 | 正/负向消息占比 | 情感词典打分 |
| 沟通主动性 | 对话由谁开启 | 直接计数 |
| 话题边界 | 拒绝/回避/冲突性措辞占比 | 关键词计数 |
| 回应投入度 | 短促应答、不表态的占比 | 关键词计数 |

## 三条硬规则

### 1. 证据不足就不说话

样本少于 3 条一律返回 `insufficient`，页面上显示「证据不足」。

这不是保守，是必要：**给出一个错的结论，比不给结论伤害大得多**——用户会拿它去
理解一个真实的人。

### 2. 每条证据必须带反例

「回复慢」的反例是「可能在忙」，「短回答」的反例是「可能只是说话习惯」。
没有反例的判断会被读成事实。

反例还必须**针对具体那条证据**：三条证据挂同一句 caveat，页面上会重复三遍，
看着像凑数（这个坑真踩过，现在有测试锁住）。

### 3. 不从单条消息推结论

所有计数都按「有多少条消息命中」计，不按词频。一条刷十个「嗯」只算 1 次。

## 已知局限

- **关键词拿不到语气**：反讽、玩笑会被误判。「改天」「下次吧」在中文里常是客套，
  未必真拒绝。
- **只覆盖本会话**：双方在其他场合的样子不在此列，样本期外也不在。
- **不区分主动/被动语态**：目前靠 `direction` 字段（我发的 / 对方发的），
  群聊里「对方」是全体合并，没有细分到具体成员。
- **不做诊断**：没有、也不该有「抑郁」「回避型人格」这类输出。

## 用法

```bash
# CLI：联系人画像会带「心理学维度」一节
python cli/mosu.py profile "张三"

# GUI：画像 → 联系人画像 → 选一个会话 → 底部「心理学维度」卡片
```

## 代码位置

- `core/psych.py` — 维度定义与证据规则
- `core/profile.py::_psych` — 接入点（复用同一批消息，避免两套口径）
- `gui/assets/views-insight.js::PsychView` — 专用渲染（证据 + 置信度 + 反例）
- `tests/test_psych.py` — 18 例，重点测「该沉默时是否沉默」

## 方法论参考

行为维度的划分参考了 [awesome-persona-skills](https://github.com/tmstack/awesome-persona-skills)
里 her-skill / yourself-skill 的「标签翻译表」思路：把「粘人」「话痨」这类抽象标签
翻译成可观测行为。本模块去掉了其中的星座参考（无行为锚点）与 MBTI 推断
（不可从聊天记录稳定观测），只保留能从数据里数出来的部分。
