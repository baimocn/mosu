# AI 的四种角色

墨溯的 AI 只有一个入口——微信聊天。要让它"什么都能聊"或"只会聊天"，只靠一条
系统提示词做不到。所以把 AI 拆成四个**可切换的角色**，每个角色由三件事定义：

1. **身份**：它是誰、该怎么回应（`persona_prompt`）
2. **红线**：明确禁止什么（`guard`）
3. **能看到的数据**：`none` / `light` / `full`（`data`）

第 3 点是关键。AI 在聊天里最大的风险是"随口给结论"。所以能看数据的人格必须先
拿到[事实层](#事实层给什么)给的可核对数字，看不到数据的人格则拿不到任何数字——
**默认状态下 AI 无法编造关于你的事实**。

## 四个角色

| id | 名称 | 干什么 | 看数据 | 长度上限 |
|----|------|--------|--------|----------|
| `listener` | 倾听者 | 少说多听，接住情绪；最多问一个顺着对方的话的问题 | 不看 | 25 字 |
| `analyst` | 分析者 | 先给结论再给数字，只引用事实层给出的统计 | 全量 | 90 字 |
| `comforter` | 安慰者 | 第一句先接情绪，之后只给一个今天就能做的小动作 | 轻量 | 60 字 |
| `mimic` | 模仿者 | 白墨本人的数字分身，用本人语气回复（原能力） | 不看 | 60 字 |

**默认是 `listener`（倾听者）。** 判断依据写在每个角色的 `intent` 字段里，
控制台悬停即可看到：

- 对方只是想找个人说话 → 倾听者（默认）
- 对方想知道具体数字、规律、对比 → 分析者
- 对方受了委屈、很沮丧 → 安慰者
- 想让 AI 以本人身份回消息 → 模仿者

为什么默认不是模仿者：logo 与文案都把墨溯定位成「倾听者 / 陪伴式对话助手」，
默认人格却是模仿者，等于产品承诺和实际第一句话不一致。倾听者「不给建议、不看数据」，
也是四条红线里最不容易出错的一条——它说错话的代价最小。
微信侧会在**首次回复后补一句**自我介绍（`core/wechat.py::PERSONA_INTRO`，
进程内只发一次），告诉对方可以发 `/模仿`、`/分析`、`/安慰` 换风格。

## 怎么切换

**控制台**：对话框上方一排角色卡，点一下即切，当前角色高亮。

**微信**：发一行指令即可，对方不用装任何东西。

```
/倾听   /分析   /安慰   /模仿
```

别名同样认：

| 中文 | 英文 |
|------|------|
| `倾听者` `倾听` `听` | `listener` `listen` |
| `分析者` `分析` `数据` | `analyst` `analysis` |
| `安慰者` `安慰` `情感` | `comforter` `comfort` |
| `模仿者` `模仿` `分身` `本人` | `mimic` |

`/help`、`帮助`、`模式` 三个词返回可用列表。

角色是**全局**状态：切换后对之后所有会话生效，这与微信里"设置"的位置无关。

### 上下文按人格分桶

`service.py::bucket_id()` 把人格并进会话 id：`{conv_id}::{persona_id}`。
同一个 `conv_id` 下，四个人格各有各的上下文，互不可见。

分桶而不是过滤，是有意的：

- **过滤**（切换人格时清空上下文）→ 用户抱怨"AI 忘了刚才说的话"
- **分桶** → 同一人格内上下文连续，跨人格不串味（分析者的数字不会漏进倾听者的耳朵）

`chat()` 里这个 `cid` **只算一次**，`_history()` 与 `_record_history()` 共用同一个值。
下游任何一处重拼都会把桶拆开，`tests/test_persona.py` 有断言守着。

存量不带 `::` 的历史文件自成旧桶，不迁移也不删除。

## 事实层给什么

`core/bot/facts.py` 把数据库统计压成可以直接引用的短句，例如：

```
- 全库消息最密集的时段：17 点（17555 条）
- 与张语桐的往来：共 1467 条，你发 740 条（50%），对方发 727 条；覆盖 75 天
- 第一句在 2026-03-19 11:58，最近一句在 2026-10-18 18:40
- 发起新对话：你更主动（你 64 次 / 对方 18 次，以间隔 6 小时以上算新一轮）
- 平均回复间隔：你 4 分钟，对方 6 分钟
- 情绪倾向（词典打分 -1~1）：你的消息 中性（+0.03），对方 中性（+0.09）
- 内容构成以 文本 1137、 图片 180 、 表情 98 为主
- 对方高频话题：日常闲聊、学习、情绪
```

（这是**节选**；实际还会给往来体量、首末消息时间、发起模式等。）

约束（有意为之）：

- 只回答"对方会问的具体问题"，不做报表
- 每条都标口径（平均/占比/条数），提示词里明确禁止改口径（不把平均说成中位）
- 禁止因果推断（"她不回是因为生气"不许说）
- 单项查询 1.8 秒超时，整体 6 秒预算；超时就少给几条，绝不拖住聊天
- 事实由数据库算出，不经过模型改写

## 与缓存的关系

语义缓存的键包含人格 id（`_cache_key` → `"{persona}:{归一化问题}"`）。
同一个问题在分析者和倾听者下答案完全不同，共用缓存会串味——这是接入人格时
最容易踩的坑。

## 代码位置

| 文件 | 作用 |
|------|------|
| `core/bot/personas.py` | 四个角色的定义、红线、别名、切换指令解析、`DEFAULT_PERSONA` |
| `core/bot/facts.py` | 事实层：数据库统计 → 可引用的短句 |
| `core/bot/service.py` | 按人格组装 prompt；人格进缓存键与上下文桶；`set_persona()` |
| `gui/server.py` | `/api/personas`、`/api/persona/set`、`/api/chat` 内支持切换指令 |
| `core/wechat.py` | 微信侧解析 `/倾听` 等指令并回执；首次回复后发一次风格告知 |
| `tests/test_persona.py` | 注册表完整性、指令解析、prompt 组装、缓存隔离、上下文分桶 |

## 会话记录与上下文

### 存哪儿

| 内容 | 位置 | 格式 |
|------|------|------|
| 对话上下文 | `~/.mosu/conversations/<安全名>-<hash8>.json` | `{convId, updatedAt, items:[{role,content}]}` |
| 语义缓存 | 进程内存（FIFO 200 条），不落盘 | — |
| 微信凭据与游标 | `~/.mosu/wechat.json`、`wechat_sync.json` | — |

`MOSU_HOME` 可覆盖整个 `~/.mosu` 位置。文件名里的 `<hash8>` 是会话 id 的 MD5 前
8 位——wxid 含 `@` 和中文，直接当文件名在 Windows 上有坑，哈希同时避免
`wxid_a1` 与 `wxid_a12` 撞名。

### 怎么用

- 每个会话保留最近 **20 轮**（一轮 = 用户一条 + 助手一条），超出即丢最旧的
- 加载时机：某会话**首次**被访问时从磁盘补齐（`self._loaded` 保证不重复载入）
- 保留 30 天，过期视为空（下次写入时覆盖）
- 磁盘不可写、文件损坏一律**静默降级为纯内存**，不让存档失败影响聊天
- 关闭：`MOSU_BOT_HISTORY=0`，或构造时 `BotService(..., store=None)`

### 隐私

对话上下文是**明文**存在你本机 `~/.mosu/conversations/`。要清空直接删这个目录，
或调 `ConversationStore.clear()`。

### 一条容易踩的坑

`store` 参数用哨兵值区分三态：

```python
BotService(corpus)                     # 落盘启用（产品默认）
BotService(corpus, store=None)         # 纯内存，不读不写
BotService(corpus, store=my_store)     # 自定义
```

早期实现写成 `store if store is not None else ConversationStore(...)`，导致
`store=None`（本意是禁用）反而创建了默认 store，单测因此读到了磁盘上的历史。
`tests/conftest.py` 统一把 `MOSU_HOME` 指到临时目录，避免测试污染真实数据。

在 `PERSONAS` 里加一条即可，缓存键、GUI、微信指令、统计都会自动派生：

```python
"coach": Persona(
    id="coach", name="教练", tagline="催你行动",
    intent="对方需要有人推他一把的时候",
    persona_prompt="...", guard="...",
    data="light", max_words=50,
    style_hint="直接、给一个能今天做的动作",
)
```

记得同时往 `ALIASES` 里加触发词，否则微信里没法切。
